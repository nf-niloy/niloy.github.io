## Overview

This third-year project used an Arduino, two temperature sensors and a local LCD to monitor battery temperature. The control logic responds to abnormal conditions through cooling, load disconnection and fault detection.

## Key features

- Dual-sensor temperature readings shown on an LCD.
- Automatic cooling and staged response to abnormal temperature.
- Emergency load disconnection and sensor-fault detection.
